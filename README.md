# Angular SPA Project

This repository contains a full-stack Angular SPA with role-based authentication, dashboard and admin modules, and a dummy Express backend.

## Structure

- `frontend/` - Angular application
- `backend/` - Express dummy API server

## Setup

1. Install dependencies
   ```bash
   npm install
   cd frontend
   npm install
   cd ../backend
   npm install
   ```

2. Start backend server
   ```bash
   cd backend
   npm start
   ```

3. Start frontend app
   ```bash
   cd frontend
   npm start
   ```

## GitHub Deployment
- Initialize Git and commit changes
- Add your GitHub remote and push to `main`

```bash
git remote add origin https://github.com/<username>/<repo>.git
git branch -M main
git push -u origin main
```
